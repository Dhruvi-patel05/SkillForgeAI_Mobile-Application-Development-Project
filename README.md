SkillForgeAI is an AI-powered Android application designed to help students and professionals improve their skills, track learning progress, prepare for placements, build resumes, and receive personalized career guidance.

This project is being developed as a **B.Tech Information Technology Final Year Project** using modern Android development practices and Firebase services.

---

## 📱 Project Overview

SkillForgeAI provides a complete learning and career development ecosystem where users can:

* Learn new skills
* Track progress
* Generate personalized roadmaps
* Prepare for placements
* Build resumes
* Receive AI-powered guidance
* Manage certifications
* Practice aptitude and interview questions

The application aims to become a one-stop platform for students preparing for internships and placements.
